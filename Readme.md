# Core Java for Automation Testing

This repository contains my Core Java learning and hands-on coding practice completed as part of the **Core Java for Automation Testers – Coding Made Easy** course by Rahul Shetty Academy.

The code covers fundamental Java concepts required for building a strong foundation in test automation.

## Topics Covered

- Java Basics
- Variables, Data Types & Operators
- Loops & Conditional Statements
- Arrays & Multidimensional Arrays
- Strings & String Manipulation
- Classes & Objects
- Constructors
- OOP Concepts
  - Inheritance
  - Polymorphism
  - Abstraction
  - Interfaces
- `this` & `super`
- Exception Handling
- Collections
  - ArrayList
  - HashSet
  - HashMap
  - Hashtable
- Date & Calendar
- Java Streams
- Coding & Interview Problems
